# UNOPAR Labs 🎓

Sistema de gerenciamento de aulas práticas — UNOPAR Parauapebas.

## Funcionalidades

- 📊 Dashboard com aulas do dia e próximas
- 📅 Calendário mensal
- 📚 Disciplinas com roteiro PDF por turma
- 📋 Importação de planilha (formato Tab)
- 🗂 Kanban por área (Engenharia / Saúde)
- 📦 Inventário por laboratório
- 🛒 Lista de compras

## Tecnologias

- React + Vite
- Supabase (banco de dados)
- Vercel (hospedagem)

## Rodar localmente

```bash
npm install
npm run dev
```

## Deploy

Hospedado na Vercel — deploy automático a cada `git push`.
